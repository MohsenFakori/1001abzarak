# هزار ابزارک

مخزن رسمی پروژه هزار ابزارک.

## وضعیت توسعه

پروژه در فاز ۱ (اسکلت پروژه و زیرساخت توسعه) قرار دارد.

## محیط توسعه محلی

محیط توسعه مستندشده فعلی:
- Windows
- Laragon
- PHP 8.3.16
- Composer 2.8.4
- Node.js 22.12.0
- npm 10.9.0
- Git 2.47.1

> این پروژه طبق تصمیم اجرایی مالک، بدون Docker توسعه داده می‌شود. این موضوع نسبت به فرض زیرساخت Docker در PRD یک انحراف مستندشده است و باید در تصمیم‌های معماری فاز ۱ ثبت شود.
