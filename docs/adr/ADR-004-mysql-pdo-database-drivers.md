# ADR-004: MySQL از طریق PDO و درایورهای پایگاه داده

- وضعیت: پذیرفته‌شده
- تاریخ: 2026-11-10

## تصمیم

پایگاه داده‌ی اصلی MySQL 8 است و Laravel از اتصال PDO استفاده می‌کند. Cache و Queue در محیط‌های هدف از database driver استفاده می‌کنند. در فاز ۱ هیچ جدول دامنه‌ای ایجاد نمی‌شود؛ فقط جداول زیرساختی پیش‌فرض Laravel مجازند.

## پیامدها

- تنظیمات اتصال از متغیرهای محیطی دریافت می‌شود.
- credentialها نباید در مخزن ثبت شوند.
- اجرای migrationها به ساخت دیتابیس محلی در MySQL Laragon نیاز دارد.
