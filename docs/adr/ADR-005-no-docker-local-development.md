# ADR-005: توسعه‌ی محلی بدون Docker

- وضعیت: پذیرفته‌شده بر اساس دستور صریح مالک پروژه
- تاریخ: 2026-11-10

## زمینه

فرض A10 و بخش ۵.۱ فاز ۱ در PRD، Docker و Docker Compose را برای زیرساخت VPS ذکر می‌کنند. مالک پروژه صریحاً درخواست کرده است که توسعه‌ی محلی بدون Docker انجام شود. محیط ثبت‌شده‌ی فعلی Windows و Laragon است.

## تصمیم

محیط توسعه‌ی محلی از PHP، Composer، Node.js و MySQL نصب‌شده در Laragon استفاده می‌کند. فایل Compose، Laravel Sail و وابستگی Docker به مسیر راه‌اندازی اضافه نمی‌شود.

## دامنه و محدودیت

این تصمیم فقط روش توسعه‌ی محلی را تغییر می‌دهد و به‌تنهایی تصمیم استقرار Production را لغو نمی‌کند. راهبرد Production و Staging باید پیش از فاز استقرار نهایی و با اطلاعات میزبان مشخص شود.

## انحراف از PRD

این ADR یک تصمیم اجرایی افزوده‌شده بر اساس دستور مالک است؛ متن PRD تغییر داده نشده است.
