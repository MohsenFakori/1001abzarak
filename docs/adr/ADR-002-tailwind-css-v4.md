# ADR-002: Tailwind CSS 4 و توکن‌های CSS

- وضعیت: پذیرفته‌شده
- تاریخ: 2026-11-10

## تصمیم

Tailwind CSS نسخه‌ی ۴ با افزونه‌ی رسمی Vite و پیکربندی CSS-first از طریق `@import "tailwindcss"` و `@theme` استفاده می‌شود. رنگ‌ها و خانواده‌های فونت پایه به‌صورت توکن تعریف شده‌اند؛ رابط نهایی در فاز ۳ پیاده‌سازی خواهد شد.

## پیامدها

- از پیکربندی قدیمی JavaScript برای Tailwind استفاده نمی‌شود.
- اجزای رابط باید به توکن‌ها متکی باشند، نه مقادیر رنگ پراکنده.
