# ADR-003: خودمیزبانی فونت و آیکن

- وضعیت: پذیرفته‌شده؛ تأمین فایل‌های مجاز در فاز ۳ تکمیل می‌شود
- تاریخ: 2026-11-10

## تصمیم

فونت‌های فارسی و کتابخانه‌ی آیکن در استقرار نهایی از دامنه‌ی خود پروژه سرو می‌شوند؛ وابستگی runtime به Google Fonts یا CDN آیکن ایجاد نمی‌شود.

## دارایی‌های مرجع

- تیتر و دکمه: Baloo Bhaijaan 2
- متن: Vazirmatn
- آیکن: Phosphor

## پیامدها و کار باقی‌مانده

فایل‌های فونت و آیکن هنوز در این Commit قرار نگرفته‌اند. پیش از فعال‌سازی UI در فاز ۳ باید فایل‌های دارای مجوز مناسب، اطلاعات مجوز و وزن‌های موردنیاز به مخزن افزوده شوند. لینک Google Fonts داخل UI Kit نباید به runtime محصول منتقل شود.
